# Discord Botの要件まとめ

本プロジェクト（Club-Abacus-System）から別プロジェクトとして分離された、Discord Botに関する要件と仕様のまとめです。

## 1. Botの役割・全体像
- **閲覧・通知専用ツール**: 日常的なコミュニケーションツールであるDiscordを活用し、部員がシステムの状況（残高、申請状況）を簡単に確認できるようにする。
- **バックエンドとの連携**: Web API経由でClub-Abacus-Systemのデータベースと連携し、情報の照会やバッチ処理による通知を行う。

## 2. 自動通知・バッチ処理機能
Webシステムでの操作をトリガーとして、Discordの特定チャンネルや個人へ自動で通知を行います。
- **新規申請通知**: ユーザーが新規で経費申請（立替払い / 事前出金）を提出した際、管理者用チャンネルに通知する。
- **承認通知**: 管理者が申請を承認した際、該当の申請を行ったユーザーへ通知する（メンションまたはDM等）。
- **大学申請・部費受け渡し通知**: 「大学へ申請完了」のステータスになった時や、立替者・事前出金者への「部費の現金手渡し」が必要な段階になった際に、会計担当者へ通知する。
- **督促通知（バッチ処理）**:
  - 同じステータスのまま長期間（例：1週間以上）処理されていない申請が存在する場合、その対応担当者（未承認なら管理者、現金渡し待ちなら会計・申請者など）へ督促メッセージを送信する。
  - 「事前出金で翌月20日が近いが領収書が未提出のデータ」などの抽出とリマインドを行う。

## 3. 購入提案（商品未定）の議論スレッド自動作成
- **スレッド自動作成**:
  - Webシステム上で「具体的な商品は未定（Discordで相談する）」という設定で新規申請が行われた際、Discordの指定チャンネルに通知を送信し、それに紐づく**専用の議論用スレッドを自動作成**する。
- **目的**: 
  - このスレッド内で「具体的にどの商品を買うか」「そもそも必要か」を部員間で議論・投票（部内投票）し、最終的な商品を決定するため。
  - （商品確定後は申請者がWebシステム上で商品URLを追記して申請を更新する運用）

## 4. スラッシュコマンド・照会機能
- **`/budget` コマンド**: 
  - 呼び出し時にバックエンドから総予算・使用済・残高を取得し、Embedで表示する。
  - matplotlib等を用いて円グラフ画像を動的に生成し、Discordへ添付・返送する。
- **`/history` コマンド**:
  - 最近の申請履歴などをDiscord上で確認できるようにする。

## 5. 部内投票・リアクション機能
- **申請の投票**:
  - 申請の承認タイミングなどで、Discord上でリアクション（投票）を受け付ける。
  - リアクションの数や種類を自動集計し、その結果をもとに会計担当者が申請を許可するフローをサポートする。

## 6. ユーザー管理と連携
- **Discord IDの紐付け**:
  - システム側（Club-Abacus-System）のユーザー情報（`discordId`）と紐付けし、個人へのメンションを可能にする。
